# busd-map

Google-Maps-style viewer for a fantasy world: zoom, pan, search, measure
distances, and compute travel time between locations (by road or straight
line). Built as a writing reference so travel in the story stays honest.

## Run

```bash
npm install
npm run build:map   # world/ -> map.png + tiles + public/data (~40s)
npm run dev
```

`npm run build` regenerates tiles automatically (`prebuild`).

## Offline / caching

A service worker (`scripts/sw.template.js` -> `public/sw.js`, generated by
`make-tiles`) precaches the whole tile pyramid, the app shell and the data on
first visit. After that pan/zoom loads nothing from the network and the map
works offline. Its cache version is a hash of the source map + config, so a
rebuilt map replaces the old cache automatically. Production builds only
(`npm run build && npm run preview`), not `npm run dev`.

## Stack

- React 19 + Vite + TypeScript + Tailwind 4
- Leaflet + react-leaflet with `CRS.Simple` (flat pixel coordinates)
- Tile pyramid (`public/map/tiles/{z}/{x}/{y}.webp`) generated with sharp
- Static JSON data in `public/data/` (map config, locations, roads, regions)

## Layout

```
world/                     editable source: terrain, locations, roads, config
world/source/              raster map the terrain was extracted from
scripts/extract-terrain.mjs raster map -> world/terrain.json (land + elevation bands, vector)
scripts/build-map.mjs      world/ -> map.png + public/data JSON
scripts/make-tiles.mjs     map.png -> tile pyramid
scripts/legacy-china/      the first placeholder (China geodata), kept for reference
public/data/            map.json, locations.json, roads.json, regions.json
src/lib/                geo math, routing (Dijkstra), URL state
src/components/         MapView, markers, route layer, measure tool, search, panel
```

## Editing the world

`world/` is the source of truth. Edit, then `npm run build:map` (~20s) to
re-render the base map, tiles and `public/data/`.

- `world/terrain.json` — land polygons + elevation bands in map px. Generated by
  `npm run extract:terrain` from `world/source/map-source.png` (colour-classified:
  blue = water, green→yellow→brown→grey = rising elevation). Re-run if the source image changes.
- `world/locations.json` — places (`id`, `name`, `type`, `x`, `y` in map pixels, optional `region`, `population`, `description`)
- `world/roads.json` — road / sea-lane graph (`from`, `to`, `kind`, `waypoints` in map pixels; lengths are computed)
- `world/config.json` — world name, distance unit, `mapWidthKm` (scale; currently an assumed 6000 km), travel modes and speeds
- `scripts/derive-placeholder.mjs` — one-off that generated the current placeholder from China geodata; not needed again

Shareable URLs: `?x=&y=&z=&from=&to=&mode=`
